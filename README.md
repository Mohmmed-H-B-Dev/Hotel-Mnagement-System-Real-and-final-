# Hotel-Managment-System


# 🏨 نظام إدارة الفنادق | Hotel Management System

نظام متكامل لسطح المكتب (Desktop Application) مبني باستخدام تقنيات **.NET**، يهدف إلى تنظيم العمليات الفندقية وتسهيل إدارة الحجوزات والعملاء والموظفين.

---

## 🔑 نظام تسجيل الدخول والصلاحيات
يعتمد النظام على توزيع الصلاحيات لضمان أمن البيانات وسهولة الإدارة:
* **حساب الموظف (Staff):** صلاحيات تشغيلية يومية.
* **حساب الإدارة (Admin):** صلاحيات كاملة لإدارة النظام والموارد البشرية.

---

## 🛠️ المميزات التقنية (Features)

### 👥 بوابـة الموظف (Staff Portal)
تتكون من 3 شاشات رئيسية بالإضافة إلى الإعدادات:
1.  **إدارة الحجوزات:** * إضافة وتعديل وحذف الحجوزات.
    * تحديد الغرف والعملاء مع ضبط التواريخ والأوقات بدقة.
2.  **إدارة العملاء:** * تسجيل بيانات العملاء (أفراد ومجموعات).
    * تتبع تاريخ الزيارات السابقة لتقديم خدمة مخصصة (Personalized Service).
3.  **عرض حالة الغرف:** متابعة الغرف المتاحة والمشغولة وتحديث حالتها.

### 🛡️ بوابة الإدارة (Admin Portal)
تشمل كافة صلاحيات الموظف، بالإضافة إلى:
1.  **إدارة المستخدمين (Users):** إضافة وتعديل حسابات الدخول للنظام (Users).
2.  **إدارة الموظفين (Employees):** قاعدة بيانات شاملة لجميع العاملين بالفندق (موظفي استقبال، عمال، إلخ).
3.  **الإدارة المتقدمة للغرف:** إضافة غرف جديدة للمنظومة وتعديل تفاصيلها الأساسية.

---

## 💻 التقنيات المستخدمة (Tech Stack)
* **اللغة البرمجية:** C#
* **بيئة العمل:** .NET Framework (Windows Forms)
* **قاعدة البيانات:** SQL Server
* **الوصول للبيانات:** ADO.NET / LINQ
